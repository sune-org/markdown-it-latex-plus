Use it

      

        

          
In the browser

          
import MarkdownIt from 'markdown-it'
import latexPlus from 'markdown-it-latex-plus'

const md = MarkdownIt().use(latexPlus)

node.innerHTML = md.render(text)  // instant, cached work included
md.latexPlus.hydrate(node)        // fills in whatever is new

          
Call both after every chunk while a reply streams. Finished formulas and figures come straight from the cache, so nothing flickers.

        

        

          
On the server

          
const md = MarkdownIt().use(latexPlus)

const html = await md.latexPlus.render(text)
const css = md.latexPlus.css()

          
Math is typeset in Node. Figures are sent as their source and drawn by hydrate() on the client.

        

      

      
Options, security notes and self-hosting are in the docs.
